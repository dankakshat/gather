# Gather Campus Events

A static campus-event discovery and registration demo built with HTML, CSS, and JavaScript. From this folder, run `python -m http.server 8000` and open `http://localhost:8000`, or publish the folder with GitHub Pages.

## Demo flows

- Browse or search the sample events and filter them by category.
- Open an event, register with a name and student registration number, and print the confirmation.
- Use **Organizer** to add, edit, or remove events. Use **Reset demo events** to restore the original sample data.

Events and registrations are stored in the current browser's local storage. This demo does not synchronize seats between different browsers or devices, and organizer access is not authenticated. Do not use it for real registrations.

This folder also includes `Campus_Event_Project_Submission.xlsx`. Confirm the working project name and fill the highlighted team and link placeholders before UMS submission.
